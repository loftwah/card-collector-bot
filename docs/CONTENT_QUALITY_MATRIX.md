## What this matrix is

Each collection is assessed on separate claims. A published card is not
automatically a reviewed profile; a sourced image is not an official licence; a
frozen achievement target is not the current roster size.

- **Identity** — one canonical subject per logical ID; no duplicate subject
  under an alias.
- **Boundary** — the adaptation, season, game or volume the collection is
  allowed to draw from; later works are named as out of scope.
- **Profile** — spoiler-safe introduction plus a fuller reviewed profile.
- **Sources** — at least one reliable source reference per card, with a
  subject-image provenance record.
- **Artwork** — a sourced subject layer, designed front and designed back.
- **Finishes** — Plain, Silver, Gold and Holographic variants.
- **Review** — `reviewed` means a human/agent identity, boundary, crop and copy
  review is recorded; `draft` is not counted as reviewed.
- **Publication / access / draws** — independent production facts.

variants and renders, aliases, collection links, pool entries and new assets,
then restores the collection release and pool revision. It is safe only while
no ownership, ledger, achievement or later pool edit depends on the new rows;
otherwise restore the pre-import JSON backup. Review the script before use.

## Collection identity and logos

Current production collection marks are reviewed Foilbury interpretations, not
official wordmarks. The public-facing originals (Bubbles, Fighter, Protocol 11,
Shared) use the Foilbury mark system and are unaffected.

Official wordmark sourcing is a separate content task:

- Prefer the property owner's press/brand page, then an official store or
  publisher page. Wikimedia/Wikipedia is a secondary source only when the file
  page records the original owner and reuse status.
- Store masters, the source URL, retrieval date, file hash, transformation
  (crop, monochrome, small-icon derivative) and the manual choice under
  `.foilbury/sourced/logos/` (gitignored).
- Distinguish **wordmark**, **small icon** and **cover**. A wordmark must not be
  squeezed into a square icon; a cover is not a logo.
- Keep the existing Foilbury initials mark as an explicit fallback where no
  usable official mark is available. Do not trace, recolour or generate an
  imitation and label it official.
- The consumer matrix is web collection tile, card front/back, draw room,
  Discord embed thumbnail, mobile, light/dark and slow/missing asset. A missing
  logo must degrade to the fallback, not a broken image.

No official logo was uploaded in this pass. The current production collection
logos remain interpretations, and that is the honest status.
