## What this release changed

- Persistent, validated **Start the Foilbury tour** entry in #card-collector-test.
- Tour album selection no longer treats eight cards as a universal ceiling; the
  progress stage reports the collection release and the achievement's frozen
  roster/version.
- Discord draw lifecycle owned by an Effect service with typed failures,
  request-scoped identity, bounded retry/`Retry-After`, cancellation cleanup,
  durable receipt and idempotent reconciliation.
- Draw commit recovery now reconciles from the deterministic draw row when the
  interaction receipt is missing or its write failed.
- Gift campaigns persist the `failed/partial → sending` transition before
  recipient effects, terminate conditionally, and a partial unique index prevents
  duplicate card gifts per recipient per campaign.
- Scheduled maintenance steps are isolated; failures are logged and can raise a
  bounded mention-free alert. The EmDash editorial handler still runs.
- Release gate: working-tree content identity, complete module/asset digest,
  fresh remote ref, immediate previous Worker version and scope evidence.
- DrawStudio explicit loading/ready/blocked/submitting/unknown/reconciling/
  committed/revealed states, durable operation payload/key, reload reconciliation,
  abort/timer cleanup and account/Bot scope reset.
- Acceptance runner: bounded session identity, exact economic correlation,
  failed/processing handling, spectator binding and 28 negative-control tests.
