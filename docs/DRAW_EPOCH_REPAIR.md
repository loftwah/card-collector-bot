# Scoped draw epoch integrity

The local candidate checks the guard on new server-scoped draws; authorised same-key receipt recovery remains available. Deployment requires full qualification and the controlled schema procedure below.

The epoch assumes every change to an eligibility dependency is observed by the 0033 triggers. The reader and draw transaction verify the exact required trigger definitions. A missing or modified trigger fails closed. These checks cannot detect a trigger that was removed, allowed writes to occur, and was recreated identically between checks: Cloudflare D1 rejects the SQLite schema-version query in the isolated Worker runtime. A privileged actor able to modify the schema can also defeat these checks. Schema changes are therefore an operational trust boundary, not an adversary this mechanism can contain.

Any schema change that can affect these triggers must first stop new scoped draws and remain under exclusive, controlled migration authority. The unexposed `repairDrawEpochTriggers` primitive reinstalls all 0033 definitions and advances the global epoch in one D1 batch; a missing epoch row or failed definition check rolls the batch back. The increment invalidates previews captured before repair. Changes during the preceding trigger gap require this repair even if the definitions now look correct. Do not run it against active or production data without the required backup, migration review and rollback plan. Its batch size and behaviour require qualification in the target D1 environment. Coordinate schema changes so that no out-of-band DDL can occur during or after repair and before release.

The primitive does not rebuild a materialized distribution: fresh previews derive the current distribution from current data. It is not an administrative endpoint and does not enable the held draw path. After controlled repair, independently verify definitions, fresh preview and transaction tests, concurrent draw tests, authorised replay and production operational controls before considering resumption.
