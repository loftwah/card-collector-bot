# Collection rosters — release brief

This is the reviewed, versioned roster brief for every launch collection. Source
manifests are private (`.foilbury/content`, gitignored); this page records the
public-safe identity, scope boundary and named release roster so a later import
cannot silently inherit an arbitrary eight-card ceiling.

Version semantics: bump `collection.release_version` when the named roster
changes. Existing serials, ownership, ledgers and frozen achievement rosters are
not rewritten. Collection achievements use `collection_unique` targets, so a
larger roster does not revoke an earned completion.

## Process stages

researched → drafted → fact-checked → art-ready → visually reviewed → published → eligible for draws.

A seeded row or four variants of one subject does not count as four characters.
Reviewed cards use a spoiler-safe introduction, a fuller profile, typed
attributes, explicit source references and a sourced subject image. Unknown
facts stay unknown.

## Deliberate boundaries

- **NBA — Opening Night** is deliberately 12 players for one club each. It is
  not a full league or all-time roster and must not be padded to match other
  collections.
- **Danganronpa** is one student from each game plus the bear, now with Gonta
  Gokuhara from V3. Late-game revelations remain out of the spoiler-safe
  profiles.
- **Vocaloid** treats the voicebank software, character persona and real voice
  provider as separate facts. Kamui Gakupo / Camui Gackpo is an Internet Co.
  persona, not a Crypton character.
- Spin-offs, films, reboots and later adaptations are excluded where the source
  context says so. Expanding a boundary requires a new reviewed version.
- Alien Stage, DDLC and two Summer Hikaru Died profiles remain draft; they are
  tracked rather than counted as reviewed coverage.

## Adding a subject

1. Search existing canonical subjects, aliases, logical IDs and adaptation
   membership before creating anything.
2. Record the source work, adaptation boundary, aliases and spoiler level.
3. Write the spoiler-safe and fuller profiles without invented facts.
4. Source a reviewed subject image and record provenance, dimensions, licence
   metadata and credit.
5. Complete Plain/Silver/Gold/Holographic fronts and the designed back.
6. Review identity, crop, small-size legibility and back layout.
7. Bump `release_version` and import through `pnpm content:provision` with a
   preview. Do not re-enable a collection that was deliberately disabled (#14).
