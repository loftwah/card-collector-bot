# Foilbury brand kit record

The asset manifests remain the source of truth: `public/brand/kit/manifest.json` records the systems, renditions, dimensions, intended uses, sizes and generation metadata; `public/brand/kit/selection.json` records the selection. The vectors and generated assets for Signal Fold, Bastion, Aperture and the earlier marks remain in `public/brand/kit/`.

Signal Fold was selected under delegated authority on 2026-11-04. The former public selection board recorded the Foilbury application icon, cover and description as applied; it recorded the Loftwah guild icon as unchanged and the server banner as blocked by the server's Boost entitlement. It also recorded the application profile banner as a Developer Portal step. These are historical notes, not a live Discord status check. The preceding application values were recorded for rollback. The two alternatives and legacy assets were retained.

The former board recorded the systems as original vector geometry derived from Foilbury marks, deterministically composed as SVG and rasterised locally with Chromium, without paid image generation. It identified Manrope and Geist as self-hosted under the SIL Open Font License 1.1. Assets and the manifest are generated by `node scripts/brand/generate-brand-systems.mjs`.

The historical board described 960×540 and 1920×1080 Discord banner assets and the recommended 48px quiet area, citing Discord's Server Banners and Server Profile support pages as checked on 2026-11-04. Entitlements and upload guidance can change and should be checked before applying an asset. The board's Discord profile images were illustrative mockups, not live client captures.
